# ExamTheory-Local: итоги работы и план проверки

Документ для продолжения работы дома. Описывает, что уже сделано в сервере (`server/server.go`) и клиенте (`lib/main.dart`), что проверить вручную и что осталось сделать.

---

## 1. Что сделано

### Сервер (`server/server.go`)

**Безопасность (пункты 1–2)**
- Вход в админ-панель `/admin` и API `/api/admin/*` защищён HTTP Basic Auth (`requireAdmin`).
- Пароль берётся из переменной `ADMIN_PASSWORD`. Если она не задана, генерируется случайный и печатается при старте.
- В панели все данные экранируются (`esc()`), клики обрабатываются через `data-act`/`data-key` (защита от XSS).

**Время и статус на сервере (пункты 3–6)**
- У каждой сессии есть `Deadline`, `Token`, `LastSeen`.
- Сервер — единственный источник времени. Клиент только отображает оставшееся время.
- Фоновый таймер раз в секунду завершает просроченные попытки.
- Все запросы студента (`/api/progress`, `/api/submit`, `/api/heartbeat`) проверяют `session_token`:
  - неверный токен → 403;
  - время вышло → 410 `time_expired`;
  - неверный статус → 409;
  - в `/api/progress` сохраняются только ответы на назначенные билету вопросы.
- `/api/submit` принимает только `submitted` и `blocked` (иначе 400). Повторная сдача → 409 с итоговым результатом, без перезаписи.
- Панель получает признак `link_lost` (связь потеряна), токен в панель не передаётся.
- «Полный сброс» / `soft_reset` добавляет 180 секунд, если осталось не больше 60 секунд, и сбрасывает токен.

**Вход и блокировки**
- Блокировка по ФИО: при повторном входе с тем же ФИО — отказ (403), кроме возобновления попытки в статусе `testing` (выдаётся новый токен).
- Блокировка по IP: только если с этого IP есть активная попытка (`testing`).

**Преподаватель**
- Действие «Завершить» (`finish`): досрочная сдача активной попытки с причиной «Завершено преподавателем», пересчёт баллов.
- Подсветка вопросов: для `multiple` сравнение выполняется по множествам оригинальных индексов (`OptionMapping`).
- Эссе не помечается как верное, в панели выделяется жёлтой рамкой (класс `q-review`, «на проверке»).
- В JS панели проверяется `resp.ok`, при ошибке сервера показывается `alert` с текстом.

**Надёжность (пункты 9–11, 18–19, 23)**
- Бэкап `backup_state.json` пишется атомарно: сначала `.tmp`, затем переименование.
- Смена банка вопросов при активных попытках (`testing`) → 409.
- Имя файла банка проверяется функцией `safeBankFileName`; ошибка загрузки банка → 400.
- Глобальный `rand.Seed` удалён, используется собственный генератор `rng`.
- Текстовые ответы нормализуются (`normalizeAnswer`: регистр, ё→е, лишние пробелы), сравниваются через `isTextMatch`.
- Таймауты HTTP-сервера: ReadHeaderTimeout 5 с, ReadTimeout 15 с, WriteTimeout 30 с, IdleTimeout 60 с.

### Клиент (`lib/main.dart`)

- Сохраняется токен сессии (`_sessionToken`), он отправляется при сдаче.
- Heartbeat каждые 10 секунд, таймаут 5 секунд. При сбое — индикатор «Нет связи» (`_linkLost`), без автонарушения.
- Очередь неотправленных ответов: `_postAnswer`, `_flushAnswers`, `_hasUnsynced`, повтор через `_retryTimer`.
- Результат показывается только после подтверждения сервера (`_finishWithResult`).
- Кнопка «Следующий студент» (`_resetForNextStudent`). При `blocked` — «Повторить вход».
- Экраны: `login`, `exam`, `result`.
- Адрес сервера: `--dart-define=SERVER_URL` → файл `server_ip.txt` рядом с exe → дефолт `http://10.164.203.35:8080`.
- Исправлены: `_getOrCreateAnswer` разделён на `_newAnswer`/`_ensureAnswer`/`_answerOrEmpty` (нет изменения состояния в `build`), единое правило «отвечен» (`_isAnswered`), проверка `mounted` в `_fetchExamInfo`.

### Админ-панель
- [ ] Список студентов, статусы, оставшееся время обновляются.
- [ ] Кнопка «Завершить» досрочно сдаёт активную попытку и пересчитывает баллы.

- [ ] Вопросы типа `multiple` подсвечиваются правильно.

- [ ] Смена банка при активной попытке возвращает ошибку (409) с понятным `alert`.
- [ ] Попытка XSS: в ФИО или группе написать `<img src=x onerror=alert(1)>` — текст должен отображаться как текст.

### Клиент и сеть

- [ ] Повторная отправка сдачи не создаёт дубликат результата.
- [ ] Текстовые ответы: регистр, ё/е и лишние пробелы не мешают засчитыванию.
- [ ] Вход с тем же ФИО с другого ПК — отказ; возобновление попытки в статусе `testing` — работает.
