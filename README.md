# ExamTheory-Local

Локальная система тестирования: Flutter-клиент на компьютерах студентов и Go-сервер с веб-панелью преподавателя. Интернет не нужен, достаточно локальной сети (LAN).

## Состав

- `lib/` — клиент (Flutter, Windows).
- `server/server.go` — сервер (Go), выдаёт билеты, принимает ответы, считает баллы.
- `server/questions*.json` — банк вопросов.
- `server/backup_state.json` — автоматический бэкап состояния (создаётся сервером).

## Запуск сервера (компьютер преподавателя)

1. Установите Go (1.21+).
2. Задайте пароль панели преподавателя (обязательно для экзамена):
   ```bash
   set ADMIN_PASSWORD=ваш_пароль        # Windows cmd
   $env:ADMIN_PASSWORD="ваш_пароль"     # PowerShell
   ```
   Если переменная не задана, сервер сгенерирует случайный пароль и выведет его в консоль при запуске.
3. Соберите и запустите:
   ```bash
   cd server
   go build -o server.exe server.go
   server.exe
   ```
4. Узнайте IP компьютера преподавателя в локальной сети (`ipconfig`) и откройте панель: `http://<IP>:8080/admin`. Логин не нужен, пароль — из пункта 2 (браузер запросит его через HTTP Basic Auth).

Порт задаётся переменной `PORT` (по умолчанию `8080`).

## Сборка клиента (компьютеры студентов)

Адрес сервера выбирается так (по приоритету):

1. Параметр сборки `--dart-define=SERVER_URL=http://<IP>:8080`.
2. Файл `server_ip.txt` рядом с готовым `.exe` (содержит адрес сервера, например `http://192.168.1.10:8080`).
3. Адрес по умолчанию в коде (`lib/main.dart`).

Команды:

```bash
flutter pub get
flutter build windows --dart-define=SERVER_URL=http://192.168.1.10:8080
```

Затем скопируйте `build\windows\x64\runner\Release` на все компьютеры. При необходимости положите рядом с `.exe` файл `server_ip.txt`.

## Проведение экзамена

- Один студент — один вход. Студент, который уже сдаёт на этом компьютере, не может начать новую попытку с другого ПК (и наоборот, пока попытка активна).
- После сдачи преподаватель нажимает «Следующий студент» на клиенте; для следующей группы студентов на тех же компьютерах используется новый вход.
- Панель `/admin`: смена банка вопросов возможна только при отсутствии активных попыток. «Завершить» досрочно засчитывает ответы; «Полный сброс» удаляет попытку целиком.
- Сетевой обрыв клиента отображается индикатором «Нет связи» и не считается нарушением. Ответы досылаются при восстановлении связи.

## Проверка

```bash
flutter analyze
flutter test
cd server
go vet server.go
```

## Важно

- Пароль панели и файлы `server_ip.txt`, `backup_state.json` не коммитьте в репозиторий.
- Изменения протокола (токен сессии, heartbeat, досылка ответов) требуют одновременной пересборки сервера и клиента.
